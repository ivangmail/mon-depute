## 2. Constats du 26/11/2026

### Efficacité des canaux

Aucune étude française n'a été trouvée. Les enquêtes du Congressional
Management Foundation auprès des collaborateurs du Congrès américain
(2011–2017) indiquent :

- la visite d'un électeur est le contact le plus influent sur un élu encore
  indécis (94 % des collaborateurs) ;
- le courrier postal (90 %) et l'e-mail (88 %) ont une influence comparable ; un
  message personnel pèse beaucoup plus qu'un message type (environ 20 % contre
  1 % pour « beaucoup d'influence ») ;
- sur les réseaux sociaux, les collaborateurs ont du mal à savoir si l'auteur
  est un électeur.

La transposition à l'Assemblée est une hypothèse. Elle conforte toutefois les
choix actuels : e-mail officiel, message qui précise que l'on habite la
circonscription, texte à compléter plutôt qu'un message type.

1. Lister tous les `typeLibelle` présents dans la table des contacts, avec leur

   aucune.

## 4. Pistes, à décider après le décompte

- **Une seule source** : ne pas compléter les contacts par Datan ou une autre
  source, pour appliquer la même règle à tous. Un compte absent des données de
  l'Assemblée reste absent.
- **Fraîcheur** : indiquer sous la liste des contacts « Contacts publiés par
  l'Assemblée nationale », avec la date du dernier chargement.
- **Permanence** : quand l'adresse de circonscription existe, ajouter une phrase
  rappelant qu'on peut demander un rendez-vous (canal le plus influent selon le
  § 2). Formulation à valider.
- **Pas de message à publier sur les réseaux** : les messages types pèsent peu,
  et un texte fourni par le site poserait une question de neutralité.
- **Règle de cohérence** : si l'une de ces pistes est retenue, la décrire dans la
  page Méthodologie (`collecte/site.py`).
